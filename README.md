# HTML & CSS Practice Projects

This repository contains beginner front-end projects created while learning HTML and CSS through independent practice and freeCodeCamp exercises.

The projects focus on layout design, responsive styling, semantic HTML, accessibility, forms, typography and visual UI development.

---

## Projects Included

### Personal Portfolio
A soft bear-themed personal portfolio page using responsive layout, navigation, project tiles, hover overlays, contact links and custom styling.

[Live demo](https://aasiyahrahman00.github.io/html-css-practice-projects/personal-portfolio/)

### Business Card
A simple digital business card using HTML and CSS with a profile image, contact details, links and basic layout styling.

[Live demo](https://aasiyahrahman00.github.io/html-css-practice-projects/business-card/)

### Magazine Layout
A responsive magazine-style layout using CSS Grid, hover effects and custom typography.

### Product Landing Page
A themed landing page featuring navigation, sections, pricing cards and responsive layouts.

[Live demo](https://aasiyahrahman00.github.io/html-css-practice-projects/product-landing-page/)

### Tribute Page
A tribute page using semantic HTML, accessible images, tables, blockquotes and styled layouts.

[Live demo](https://aasiyahrahman00.github.io/html-css-practice-projects/tribute-page/)

### CSS House
A decorative CSS art project using positioning, shapes and layered elements.

### Event Flyer
A responsive event flyer page using flexbox layouts, semantic sections and themed styling.

### Playing Cards

[Live demo](https://aasiyahrahman00.github.io/html-css-practice-projects/book-inventory-app/)
